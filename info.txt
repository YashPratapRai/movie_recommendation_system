Best 30-Second Interview Explanation

This project is a FastAPI-based movie recommendation backend integrated with TMDB API and
a local TF-IDF recommendation system. I used async API calls with httpx for performance,
Pydantic models for validation, and startup events to preload ML resources like TF-IDF 
matrices and datasets. The backend provides movie search, movie details, genre-based recommendations,
and content-based recommendations through REST APIs, which are consumed by a Streamlit frontend.
